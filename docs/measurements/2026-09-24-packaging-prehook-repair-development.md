# Packaging #928 PreToolUse repair pair: exposed development result (2026-09-24)

This pair tested whether a temporary `PreToolUse` rewrite that captures a long failing verifier result preserves repair behavior and reduces full-task usage. It used the already-exposed [packaging #928](https://github.com/pypa/packaging/issues/928), parent `3f83dea9b60e660e464535a1019d2de62723884f`, and historical fix `a1f705642e50b79da6be83fb0f6149daa32fc7cc`. The [visible regression patch](../../experiments/packaging_928/visible_regression.patch) makes `((MIT))` fail in the parent and pass in the fix. The exact [14-case external verifier](../../experiments/packaging_928/verify_packaging_frozen.py), SHA-256 `841776fda08a41df4f0c652dda02a0b440d8b08dbaf5e16231520d3dcc1d4324`, scored the parent 8/14 and historical fix 14/14 before the agent runs. The historical fix passed 27,294 upstream tests with one skip in the frozen evaluation environment.

Direct ran first, then receipt. Each fresh ephemeral `gpt-6-luna` low-effort session received the same root-normalized task prompt and the same failing `python -m pytest -v tests/test_metadata.py -o addopts=` as its first command. The receipt arm used a temporary local hook to replace that exact Bash command with `receipt_command.py`, leaving the complete output in an agent-readable local artifact. The installed SoL Codex plugin was disabled. Both arms used the same parent fixture, Python environment, code mode, host-only credential broker, and outer macOS Seatbelt. Canaries verified that the agent could read its own workspace but received `PermissionError` for the host credential and host evidence directory. A process supervisor checked for remaining descendants and open workspace handles before the host took an anchored, no-follow snapshot. The clean-copy evaluator denied network and agent writes to source, tests, and private reports. These checks provide development containment, not a confirmatory isolation attestation.

Both agents changed only `src/packaging/licenses/__init__.py`. Their patches were byte-identical to each other, passed `git diff --check`, and produced the same Python AST as the historical fix for that module. The first failing command exited 1 in both arms; each agent reran it after the edit and got exit 0. The receipt agent also made three bounded retrieval attempts, the first with incorrect arguments. The first result was 93.8% smaller in the receipt arm, but its full run used **51,943 more input-plus-output tokens (+45.8%)** and **54.439 more seconds (+88.7%)**. Its uncached input count was 8,833 lower while cached input and output were higher; these categories are not a reconciled provider bill.

The original frozen adherence auditor wrongly required the diagnostic to run **exactly once across the entire repair**, rejecting both arms when they repeated it to verify their edits. The original failed reports and their hashes are retained in the [aggregate](data/2026-09-24-packaging-prehook-repair-dev.json). After **both** model runs, the auditor was revised to require the first exact command and complete, counted repeats; the receipt arm must have a matching hook event for each exact repeat. Both runs then passed the revised audit without rerunning either model. The external evaluator had been frozen and preflighted on the historical fix before the arms, but evaluation was invoked after this audit revision. The revised qualification is therefore **post hoc and developmental**, not a prospective acceptance gate.

The [fixed-field reducer](../../experiments/packaging_928/reduce_prehook_repair_dev.py) reads the two private host-artifact directories and a pinned historical-fix source file, validates design hashes, original and revised audits, complete request usage, source overlays, and clean-copy evaluation, then emits the path-free aggregate. Raw model traces, authentication, workspaces, and request bodies remain private; their hashes bind the published observations. One exposed task, fixed arm order, different tool trajectories, possible cache effects, a temporary rather than installed hook, no blinded independent acceptance review, and no provider billing reconciliation prevent a causal or general savings claim. This pair supplies a negative development observation for the complete repair workflow despite successful local output suppression and passing measured behavior.
