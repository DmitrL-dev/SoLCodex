# Python repository metadata pilot: first 20 of 687 names

**Status: metadata capture only; six redirects unresolved; ancestry review pending; no task selected.** The [aggregate](data/2026-09-25-quiet-python-repository-probe-pilot.json) comes from the lexicographic first 20 names in the private 687-name queue derived from the [pinned Python projection](../research/2026-09-25-quiet-python-projection.md). This is an instrumentation pilot, not a representative sample or an ancestry estimate. No task IDs, patches, outcomes, ranked order or repository names are published.

The [probe](../../scripts/probe_quiet_python_repositories.py) made exactly **20 unauthenticated GitHub REST requests** in series, one per queue entry. Fourteen returned `200` with valid repository metadata; six returned `301` with API-host `Location` headers. Automatic redirect following was disabled, so those six destinations still need separate capture and review. Among the 14 `200` responses, none reported `fork=true`, `parent` or `source`. Four returned names differed in exact spelling from the requested names, but none differed after case folding. These fields do not establish independence, and the 20-name lexical prefix cannot estimate the remaining 667 names. GitHub documents `parent` and `source` for forks in its [repository endpoint](https://docs.github.com/en/rest/repos/repos#get-a-repository); absence of those fields does not rule out mirrors or project continuations.

The private queue and response journal are mode `0600`; their SHA-256 hashes and the exact probe and [aggregate summarizer](../../scripts/summarize_quiet_python_repository_probe.py) hashes are recorded in the aggregate. The journal records a durable start before each request, the response body and hash, status, headers and timestamp. A lock prevents concurrent writers. A truncated journal or unanswered start stops automatic resume for manual recovery. The cumulative pilot limits are 20 queue entries and 40 HTTP attempts. The client stops at rate headers and cooldowns; GitHub's [unauthenticated REST limit](https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api) is shared by outbound IP. API observations can change over time, so replay of the current endpoint may differ from this pinned capture.

The [separately budgeted follow-up](2026-09-25-quiet-python-redirect-probe-pilot.md) has since captured metadata at the six numeric redirect destinations. Capture still needs to extend beyond this pilot, and two curators must inspect forks, mirrors, migrations, common upstreams and every link to the global development-exposure list. The [scoped ancestry approval](../research/data/2026-09-25-quiet-python-lineage-map-approval.json) remains `pending`. GitHub metadata alone cannot approve it or authorize the [24-task selector](../research/2026-09-25-quiet-python-sample-selector.md).
