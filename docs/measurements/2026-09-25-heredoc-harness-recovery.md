# macOS sandbox heredoc recovery (development)

The [explicit receipt model pair](../../experiments/explicit_receipt_profile/report.md) showed a failed ON shell heredoc before the agent retried its edit with a file-change tool. The ON branch used two more provider attempts and 19,139 more tokens than OFF, but one pair cannot attribute that difference to either the receipt or the shell failure. This note isolates a measurement-harness defect that can independently add repair turns.

In the **same frozen ON sandbox profile and workspace**, the original environment had `TMPDIR` but no `TMPPREFIX`. A harmless Python heredoc exited 1 with `zsh: can't create temp file for here document: operation not permitted`. Adding `TMPPREFIX` under the already permitted private temporary directory made the same command exit 0. The [reproduction script](fixtures/2026-09-25-heredoc-recovery-probe.py) checked the affected trace hash against the published model result and recorded [path-free aggregate evidence](data/2026-09-25-heredoc-harness-recovery.json).

The revised [harness source snapshot](fixtures/2026-09-25-live-pilot-tmpprefix.py) sets `TMPPREFIX` and runs an actual sandboxed heredoc canary before launching a model. Its SHA-256 differs from the runner pinned in the previous model-pair plan. A separate no-model real-CLI smoke using a synthetic provider passed the new canary, two provider requests, complete reconciliation and process cleanup. The smoke did not run a model or assess repair quality.

The previous pair stays frozen: both quality results remain 14/14, ON remains 19,139 tokens above OFF, and both first-action audit results remain `unknown` because of a separate pre-turn `code_mode` warning. No model arm was rerun or reclassified. Future model protocols must pin the revised runner and demonstrate all canaries before their first assigned arm. The retained private sandbox profile, traces, evaluator and model responses are not published, so the public code and aggregate support a bounded audit but not an independent replay of the original runs.
