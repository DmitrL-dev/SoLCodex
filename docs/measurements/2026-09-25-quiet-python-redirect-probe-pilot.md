# Follow-up on six GitHub API redirects in the Python pilot

**Status: redirect metadata captured; ancestry review pending; no task selected.** The [first 20-name pilot](2026-09-25-quiet-python-repository-probe-pilot.md) recorded six `301` responses. Each `Location` was a GitHub API `/repositories/{id}` endpoint. The [follow-up probe](../../scripts/probe_quiet_python_redirect_targets.py) derived a separate private queue from that pinned journal and made **six explicit, serial requests** without automatic redirect following. Its cumulative limit was six HTTP attempts; a resumed run made zero further requests.

All six numeric endpoints returned `200` with valid repository metadata. In every response, the repository `id` matched the requested endpoint; six distinct current `full_name` values were observed, each different after case folding from its original requested name. All six reported `fork=false`, with no `parent` or `source` field. This is evidence that GitHub associated six old names with six current repository IDs at the capture time. It does not establish how those projects relate to other candidates, exposed projects, mirrors or continuations. The [published aggregate](data/2026-09-25-quiet-python-redirect-probe-pilot.json) keeps these counts and the hashes of both private queues and journals, the source aggregate, the probe code and the [summarizer](../../scripts/summarize_quiet_python_redirect_probe.py). No repository names, task IDs, patches or outcomes are published.

This follow-up covers only redirects within the lexicographic first 20 of 687 direct repository names. The other 667 have no API capture under this pilot. GitHub documents [redirect handling](https://docs.github.com/en/rest/using-the-rest-api/best-practices-for-using-the-rest-api#follow-redirects) and [fork parent/source fields](https://docs.github.com/en/rest/repos/repos#get-a-repository); the numeric endpoint shape here is an observation from the captured `Location` headers, not a claim that this endpoint is a stable published API contract. Repository metadata can change. Full ancestry and exposure review by independent curators remains required before [lineage approval](../research/data/2026-09-25-quiet-python-lineage-map-approval.json) or the [24-task selector](../research/2026-09-25-quiet-python-sample-selector.md).
