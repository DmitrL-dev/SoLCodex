# Frozen real-CLI cancellation and late-accounting control

**Status: prospective one-case no-model development control.** The [expectations](data/2026-09-25-real-cli-late-checkpoint-expectations.json), [controller snapshot](../measurements/fixtures/2026-09-25-real-cli-late-checkpoint-probe.py), [first-diagnostic parser](../measurements/fixtures/2026-09-25-real-cli-first-diagnostic-audit.py), [preflight gate](../measurements/fixtures/2026-09-25-real-cli-late-checkpoint-gate.py), and [reducer](../../scripts/reduce_real_cli_late_checkpoint_probe.py) are fixed before the scored run. Earlier exploratory runs established the tool-call and cancellation behavior but do not count as scored evidence. No model run is authorized by this control.

The actual pinned Codex CLI runs in the private sandbox against the packaging regression. Synthetic provider response 1 directs the CLI to run the exact failing diagnostic. Response 2 directs it to apply the known valid source patch through Code Mode. The provider holds response 3 until the supervised CLI runner finishes. The runner has a 10-second limit inside a 45-second shared deadline, allowing the third provider completion to arrive after CLI cancellation while the bridge remains open. The host then checkpoints source and calls the real external evaluator.

Before the run, the gate compares 20 private source and test hashes, the three published source copies, the CLI binary, Python, baseline tree and evaluator/runtime digests to the expectation file. Pass requires the completed first diagnostic with exit `1` and the expected `1 failed, 290 passed` signature; an incomplete whole-turn trace is expected after cancellation. The first-command parser may classify that completed diagnostic as `observed` only when the supervisor reports timeout and verified process cleanup. It must retain `trace_complete=false`. A malformed or duplicate completion is still unknown.

The gate also requires the third request after the patch, provider completion after the runner, three reconciled attempts, the gold source tree, and a passing independent evaluator. Expected synthetic usage is 390 input tokens (195 cached) and 90 output tokens. The CLI process is expected to exit under `SIGTERM` (`-15`), while the technical evidence path completes. A successful no-model control does not qualify real provider billing, live repair quality, ON/OFF effects, or SoL Codex savings. Private execution and full evaluator artifacts cannot be independently replayed from this repository; the reducer checks only the published aggregate.
