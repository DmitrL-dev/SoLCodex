# Scoped Python lineage ranking for the quiet screen

**Status: implementation proposed; ancestry approval pending; no lineage ranking or task sample published.** The [Python projection](2026-09-25-quiet-python-projection.md) fixes 7,124 candidate rows across 687 direct repository names. [`scripts/rank_quiet_python_lineages.py`](../../scripts/rank_quiet_python_lineages.py) checks that private projection against the published aggregate, pinned source ranking hash, exact language predicate, complete candidate order and current helper hashes. It reuses the [confirmation lineage ranker's](../../scripts/rank_confirm_lineages.py) grouping and ranking function without changing the confirmation corpus or its approval.

The private lineage map must cover **all 687 direct candidate repository names exactly once**, even if some groups are excluded for development exposure. Evidence review must trace relevant upstreams, forks, mirrors and project continuations outside the Python pool, including non-Python source labels. Such external names are evidence or exposure witnesses, not extra candidate repositories. Any group linked to a development-exposed repository needs an `exposure_witnesses` entry drawn from the global exposure manifest. Unresolved ancestry blocks approval; the current ranker cannot safely mark an unresolved group eligible. A repository name or language label alone is not an independence finding.

The [separate scoped approval](data/2026-09-25-quiet-python-lineage-map-approval.json) must bind the private map and ancestry-evidence bytes, projected candidate file, full source ranking, exposure manifest, projection code and dependencies, shared lineage ranker and scoped wrapper. Two distinct independent reviewers must replay the full source export and Python projection against their pinned hashes, then audit the complete map, evidence and exposure links before recording approval. The evidence file uses `solcodex.quiet-python-ancestry-evidence.v1` with one resolved record per map group: exactly matching direct repositories and exposure witnesses, external repository names, and nonempty evidence references. The wrapper rejects missing, duplicate or unresolved records and exposed external names without a matching witness. These are structural checks; reviewers must establish the factual ancestry relationships. Approval is currently `pending`; the CLI refuses to write a ranking. A local edited `approved` value is not proof of public approval: the coordinator must verify the approved manifest in a public Git commit.

The wrapper writes a no-replace mode `0600` private ranking and prints counts only. Even after approval, its lineage groups would establish independence only according to the reviewed map; unknown mirrors, model training exposure, task executability and behavior quality remain open. The existing [24-task selector](2026-09-25-quiet-screen-selector.md) still uses the broader map gate and cannot consume this scoped ranking until a separate selector revision and approval. No task selection or model run is authorized by this stage.
