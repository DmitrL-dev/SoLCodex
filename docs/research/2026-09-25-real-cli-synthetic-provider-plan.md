# Frozen real-CLI, synthetic-provider diagnostic control

**Status: prospective one-case development control. No model call is authorized.** The [expectations](data/2026-09-25-real-cli-synthetic-provider-expectations.json), [provider/controller snapshot](../measurements/fixtures/2026-09-25-real-cli-synthetic-provider-probe.py), [preflight gate](../measurements/fixtures/2026-09-25-real-cli-synthetic-provider-gate.py), and [reducer](../../scripts/reduce_real_cli_synthetic_provider_probe.py) are fixed before the scored rerun. Earlier exploratory runs determined the wire shape; they are not scored evidence.

The private harness copies the pinned packaging baseline and runtime into a sandbox, runs the actual Codex CLI 0.155.0-alpha.16.3 with `exec --json` and Code Mode, and routes exactly two requests through the loopback Broker/HostBridge to a synthetic provider. The first provider response contains a `custom_tool_call` with `namespace="functions"`, `name="exec"`, a fixed call ID, and JavaScript that asks `exec_command` to run the specified quiet diagnostic. The second response terminates the turn. Before any model request, the gate compares the private harness source, published controller copies, CLI binary, Python, baseline tree, and runtime digests with the frozen expectation file.

Pass requires a CLI-generated trace with one exact first diagnostic and exit `1`, its expected `1 failed, 290 passed` signature, no prior action, and a second request containing the call and corresponding output with the same ID. Both transport ledgers must reconcile exactly two complete synthetic usage records (320 input, 190 cached input, 80 output). The process group must be cleaned up, source unchanged, checkpoint captured, and real external evaluator run. The evaluator is expected to **fail** because this control performs no repair. Technical-path completion and repair quality are separate outcomes.

The provider replies and usage counts are synthetic. A pass establishes only that this pinned CLI accepts this particular tool-call shape and that the observed diagnostic flows through the existing accounting, checkpoint, and evaluator path. It does not qualify real provider billing, model repair quality, Code Mode across other tool shapes, ON/OFF comparison, or SoL Codex savings. Private source snapshots and execution artifacts cannot be independently replayed from this repository; the public reducer only recomputes the decision from the published aggregate.
