# Python metadata projection for the quiet diagnostic screen

**Status: metadata projection complete; ancestry and task review pending; no sample selected.** The [published aggregate](../measurements/data/2026-09-25-quiet-python-projection.json) records a deterministic projection of the pinned 31,797-row candidate ranking to rows whose source `language` field is exactly `python`: **7,124 tasks across 687 direct repository names**. The private projection is mode `0600` and SHA-256 pinned. Ranked IDs, patches, test patches, and review records are not published.

[`scripts/project_quiet_python_candidates.py`](../../scripts/project_quiet_python_candidates.py) checks the exact private ranking hash, source and revision, every candidate's allowlisted fields and task rank, unique identities, and frozen order. It rejects outcome-bearing fields and writes a private no-replace result. The projection prints only counts and records hashes of its three imported helpers. Its three synthetic tests cover mixed languages, order, duplicate or altered IDs, an injected patch field, the source-hash gate, private permissions, and no-replace behavior. The [metadata export and ranking procedure](2026-09-24-candidate-ranking.md) allows an external reviewer to recreate the source before this projection; the private candidate IDs remain undisclosed until the once-only analysis.

The source language label defines this screen's sampling frame; it does **not** prove that a task is runnable Python/pytest. Curators must check that separately. Tasks with other labels are excluded by the frozen predicate, even if later inspection suggests Python code. Exposure exclusions remain global across languages. The full lineage map for this projected pool must cover all 687 candidate repository names, while ancestry evidence may involve non-Python upstreams, forks, mirrors or project continuations outside the pool. Links to any exposed lineage exclude the affected group. Unresolved ancestry cannot be silently treated as independence.

This is a new Python-only sampling frame. Its lineage ordering may differ from a map of all 3,607 repository names, because removing non-Python members changes group hashes. The [confirmation selector](2026-09-24-sample-selector.md) retains its broader corpus and approval gate. The existing [24-task selector](2026-09-25-quiet-screen-selector.md) still requires the unapproved full map; it must be revised and separately approved for this projection before it can select anything. The 687 direct names are not 687 proven independent lineages, and model training exposure remains unknown.
